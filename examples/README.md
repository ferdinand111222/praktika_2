# Примеры входных данных

Аудиофайлы — двоичные, поэтому в репозитории они не хранятся.
Их создаёт команда `run.bat examples` (или `python -m src.samples`):

| Файл        | Что внутри                                      |
|-------------|-------------------------------------------------|
| `1.ogg`     | нота ля, 440 Гц, 1 секунда, моно                |
| `2.ogg`     | аккорд до мажор (262, 330, 392 Гц), 2 секунды   |
| `3.ogg`     | стерео: 440 Гц слева, 660 Гц справа, 1,5 секунды |
| `4.ogg`     | 300 Гц с низкой частотой дискретизации 8000 Гц  |
| `5.ogg`     | тишина, 0,5 секунды                             |
| `error.ogg` | текст вместо звука — пример ошибки              |

После `run.bat examples` рядом появятся файлы `1.mp3` – `5.mp3`.
