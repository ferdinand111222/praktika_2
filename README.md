# Практическая работа №2, вариант 15

HTTP API для выполнения вычислительных задач.

## Общее описание

Этап 1 — **утилита командной строки** `src/tool.py`. Она принимает файл
с числами (через пробел или с новой строки) и печатает в стандартный
вывод их количество, сумму, минимум, максимум и среднее. Если в файле
есть не число или чисел нет совсем, утилита пишет ошибку в поток ошибок
и завершается с кодом 1.

## Структура проекта

```
src/
  tool.py          утилита командной строки
tests/
  test_tool.py     тесты утилиты (hypothesis)
examples/          5 примеров входных данных + пример с ошибкой
run.bat, run.sh    команды запуска
```

## Функции

- `solve(text)` — считает статистику по числам из текста и возвращает
  строку с результатом.
- `to_number(word)` — переводит слово в число, иначе выбрасывает
  `ValueError` с понятным текстом.
- `main()` — читает имя файла из командной строки (`argparse`), печатает
  результат или ошибку.

## Команды

Нужен Python 3.10+. Windows — `.\run.bat`, Linux/macOS — `./run.sh`.

```
.\run.bat install      установить зависимости (requirements.txt)
.\run.bat examples     запустить утилиту на всех примерах
.\run.bat tool FILE    запустить утилиту на своём файле
.\run.bat test         запустить тесты
```

`tests/test_tool.py` проверяет функцию `solve` на случайных списках
чисел, которые генерирует hypothesis.
